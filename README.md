# Домиан · Шахты на Маяковского

Многостраничный статический сайт универсального офиса недвижимости. Основные маршруты — покупка, продажа и предварительная оценка квартир, домов, новостроек, участков, коммерческой недвижимости, гаражей и парковочных мест в Шахтах, Каменоломнях, Новошахтинске, Аюте и Красном Сулине. Новые дома остаются самостоятельным сильным направлением, но не определяют весь сайт.

Проект не переносит публичный контент, бренды или данные доноров. Пустые каталоги намеренны: в публикацию попадают только записи с `verified: true`.

## Визуальная система и контакты

Интерфейс построен на самостоятельной светлой редакционной системе «жемчуг / холодная мята / шалфей / шампанское». Архитектурная сетка остаётся лёгким навигационным мотивом, а deep-sage секции используются дозированно. Токены и правила применения собраны в [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md).

Подтверждённые WhatsApp, Telegram, MAX и Instagram хранятся только в `site.config.json` и из него попадают в контакты, страницу Марии, мобильное меню и футер. Портрет Марии хранится в оригинале и в трёх адаптивных WebP-размерах; QR-скриншоты не публикуются.

## Локальный запуск

Требуется Node.js 22+.

```bash
npm ci
npm run build
npm run dev
```

Откройте `http://127.0.0.1:4173/DomianShakhty/`.

Полная локальная проверка:

```bash
npx playwright install chromium
npm run qa
npm run lighthouse
```

## Режимы публикации

`site.config.json` управляет одним генератором для двух режимов.

- `prelaunch`: путь `/DomianShakhty/`, `noindex,nofollow` на каждой странице, `robots.txt: Disallow: /`, без canonical, sitemap, `og:url` и `og:image`.
- `production`: корневые URL, `index,follow`, canonical, sitemap, production JSON-LD и OG URL. Для включения требуется подтверждённый `productionOrigin`.

GitHub Pages сейчас разворачивает именно PRELAUNCH. Переключение на production выполняется только после завершения [чек-листа запуска](LAUNCH_CHECKLIST.md).

## Данные

- `src/data/listings.json` — отдельные объекты.
- `src/data/projects.json` — проекты/предложения застройщиков.
- `src/data/showcase.json` — карточки направлений, которые никогда не смешиваются с реальными объектами.
- `src/data/builders.json` — отдельный будущий фид; остаётся пустым, пока офис не подтвердит конкретные отношения и право на публикацию.
- `src/data/locations.json` — география.
- `src/data/guides.json` — информационные материалы на основе открытых источников.
- `src/data/listing.schema.json` — обратно совместимый контракт будущей карточки квартиры, дома, участка, коммерческого объекта, гаража или парковочного места.

Нельзя менять `verified` на `true` без проверки источника, актуальности, права на публикацию, цены и статуса объекта. Сайт не использует автоматически полученные объявления как собственную базу.

## Формы и аналитика

В PRELAUNCH внешняя отправка и Метрика отключены. Формы передают внутри страницы цель, тип недвижимости, рынок, территорию, исходную страницу и источник CTA, честно сообщают об отключённой отправке и оставляют введённые данные в полях; заявка не сохраняется в `localStorage` и не имитирует успех.

После отдельного согласования:

1. Укажите ключ Web3Forms в `web3formsAccessKey`.
2. Проверьте договорные и трансграничные условия обработчика до передачи персональных данных.
3. Укажите ID Метрики в `metrikaId` и подтвердите финальную политику cookies/аналитики.
4. Проведите реальную тестовую отправку и проверьте получателя.

## Автоматизация

- `npm test` — сборка и статические тесты.
- `npm run seo:audit` — H1, metadata, JSON-LD, ссылки, локальные изображения и indexation guard.
- `npm run donor:audit` — защита от утечки донорских названий и географии.
- `npm run test:browser` — Playwright: страницы, меню, формы, калькулятор, каталог, console/network и адаптивность.
- `npm run lighthouse` — локальный baseline; JSON-артефакт игнорируется, сводка сохраняется в `LIGHTHOUSE_BASELINE.md`.

CI проверяет pull request, а отдельный workflow публикует `dist` из `main` в GitHub Pages.
