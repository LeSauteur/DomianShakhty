# Карта районов на главной — 19.10.2026

Ветка `codex/hero-district-map-2026-10`, база `f1ea262` (main с PR #45). Подготовлено к просмотру через PR; слияние и публикация не выполняются.

## Изменения

- Фото первого экрана заменено локальной картой: SVG-геометрия и HTML-кнопки. Прежние файлы изображений сохранены, preload главной удалён. Остальные страницы с фотографиями первого экрана сохранены.
- При сборке считаются только доступные, подтверждённые объявления без демонстрационных записей, по тем же правилам доступности, что использует каталог. Одно объявление с двумя домами считается один раз. Проданное или снятое объявление исчезает из подсчёта при следующей сборке.
- При нуле объектов карта показывает «Под запрос», `textEmpty` и «Оставить запрос». Числа в данных не зафиксированы; `countInMockup` не перенесён. Тесты также не закрепляют сегодняшние числа навсегда.
- Если одно объявление подходит двум районам, сборка завершается ошибкой с ID объявления и названиями районов.
- Выбор района работает мышью, Enter и кнопками ленты. Активное состояние — `aria-pressed`, карточка — `aria-live="polite"`. Нажатие кнопки подбора переносит район в существующую форму.
- Без JavaScript остаются заполненная карточка Центра и ссылки на разделы для всех районов. Без JavaScript лента доступна также на компьютере.
- Нет внешних карт, тайлов, библиотек или запросов карты. Указано авторство OpenStreetMap со ссылкой на лицензионную страницу.
- Знак D скопирован побайтово из переданного файла в `assets/brand/domian-d.svg`; шапка и логотип сайта не менялись.
- Из текста главного экрана изменена только подводка. H1, title, description, кнопки, портрет Марии и существующие разделы сохранены. Sitemap, индексация и редиректы не менялись.

## Отличия от макета

- Сохранены существующие шапка, H1, три кнопки, ссылки территорий и фон первого экрана сайта. Упрощённая шапка и логотип из демонстрационного HTML не переносились.
- До 1120 px карта размещается под вводным текстом: это сохраняет читаемость подписей на 1024 px. На компьютере карта справа, на телефоне — горизонтальная лента.
- Подписи «Город Будущего» и «Соцгородок» сдвинуты вверх на 14 и 8 px, чтобы исключить пересечения. На телефоне активные подписи размещаются над точками с поправкой для краёв карты.
- У точек область нажатия 44×44 px, у районов без объявлений добавлена подпись «Под запрос».
- В плотной группе точек на телефоне пересекающиеся области нажатия выбирают ближайшую точку. Явное нажатие подписи и Enter выбирают указанный район. Проверены центры всех 14 точек на телефоне.
- Карточка использует H2 по иерархии страницы. Отметка офиса загружает отдельный локальный SVG. Цвета деталей взяты из переменных действующего сайта.
- Строка авторства OpenStreetMap является рабочей ссылкой.
- После такого же сглаживания координаты SVG округлены до целых единиц viewBox: отклонение до 0,5 единицы, меньше одного экранного пикселя на проверенных ширинах. Это сокращает разметку примерно на 7 КБ.
