## Данные, которые нужны от Марии

В `src/data/office-pending.json`:

- `stats`: годы работы и число сделок с определением периода подсчёта.
- `banks`: названия банков, подтвердивших аккредитацию офиса.
- `certificates`: названия и файлы сертификатов.
- `messengers`: подтверждённые MAX / Telegram именно офиса. Существующие личные контакты Марии в site.config.json сохранены.
- FAQ `capital`, `timing`: ответы о материнском капитале и длительности сделки.

После заполнения данных и подтверждения можно включить соответствующий `publish`. Сейчас эти блоки и ответы отсутствуют в dist.

## Проверки и вес

Проверки: `npm ci`, полный `npm run qa` — **85 статических и 113 браузерных тестов**, SEO / donor audit успешно; дополнительные тесты отправляют заявки только в mock-обработчик. Портрет Марии, данные объектов и существующие SEO-метаданные сохранены. Запрещённые фразы из задачи в публичном выводе отсутствуют.

- Главная: 102646 → 115779 байт HTML.
- HTML + общие CSS/JS: +34059 байт, меньше 60 КиБ.
- Полная прокрутка в Chromium 1440: 3802813 → 3289780 байт; 375: 3770833 → 3257800 байт. Новых внешних библиотек и сервисов нет.
- `content-report.json`: фактические количества объектов и размер файлов.
- `network-weight.json`: перечни загруженных ресурсов до/после. Повторить: `node _tools/pump-weight.mjs` при работающем `npm run dev` на порту 4173.
- `browser-report.json`: currentSrc, ширина документа, битые картинки и ошибки консоли на 1440 / 375. Повторить: `node _tools/pump-screenshots.mjs`.

Ссылки MAX сверены с официальной документацией: https://dev.max.ru/help/deeplinks. Поделиться открывает выбор получателя; кнопки прямой связи офиса включаются отдельно после подтверждения контактов.

## Отличия от Квартала

Структура блоков сохранена в палитре и типографике Шахт; используется сетка и доступные вкладки с управлением клавиатурой. Все факты местные. Нет утверждений о популярности объектов, страховании, готовых платежей, неподтверждённых банков и цифр офиса. Ростовские ЖК уступают место местным комплексам. Доступна одна квартира в новостройке, поэтому соответствующая вкладка короче остальных.
