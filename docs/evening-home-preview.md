# Изолированная концепция главной

Адрес после публикации: `/previews/evening-home.html`.

Разработано в ветке `codex/evening-home-preview` и отдельном worktree. По уточнению пользователя использован существующий контент сайта: фотографии объектов, Марии Ворониной, офиса, команды и территорий. Новые сцены и изображения с животными не создавались.

## Изоляция

- Страница формируется функцией `renderEveningHome` в `src/evening-home.mjs`.
- Оформление: `assets/css/evening-home.css`. Поведение: `assets/js/evening-home.js`.
- Основной `renderHome`, `assets/css/site.css`, данные объектов и команды не изменены.
- Превью имеет `noindex,follow`, собственный canonical и изображение для отправки ссылки. Его адрес исключён из sitemap и не добавлен в меню действующего сайта.
- Публикация выполняется штатно через PR в main. В main добавляется только отдельная страница и её ресурсы; текущая главная сохраняется.

## Содержание и действия

Вечерний первый экран, преимущества, история выбора, три направления, восемь реальных предложений с исходными ценами и фото, блок собственника, пять территорий, этапы сопровождения, поиск, форма обращения и контакты.

Фильтры и прокрутка предложений работают локально. Поиск передаёт тип, территорию и бюджет в существующий каталог. Форма использует действующий обработчик Web3Forms; в браузерном тесте запрос перехватывается, реальная заявка не отправляется. Ссылки на объекты и внутренние разделы ведут на действующий сайт, поэтому их оформление пока остаётся прежним.

Использованные шрифты Cormorant Garamond и Manrope размещены локально в `assets/fonts/evening`; лицензии OFL сохранены рядом. Дополнительные библиотеки интерфейса и новые runtime-зависимости не подключались.

## Контроль

- Отдельные тесты проверяют изоляцию, исходные цены, наличие портрета Марии, фильтры, поиск и данные заявки.
- Браузерные размеры: 320, 390, 820 и 1440 px; дополнительно выполняется визуальная проверка desktop/mobile, currentSrc, загрузки фотографий и отсутствия ошибок консоли.
- Перед публикацией обязательны `npm ci` и полный `npm run qa`.

Для продолжения дизайна меняйте отдельный модуль превью и его ресурсы. Перенос нового оформления на `/` и внутренние страницы — следующий этап после одобрения собственником.
