# Внешнее сравнение

16 сравнений: 3 страницы для каждого из houses/apartments/lands/Каменоломней и 4 по кадастру. Это сравнение структуры, не текущих позиций или качества исполнения услуг. Кадастровые страницы представляют одну доступную компанию; это не исследование четырёх организаций. Региональный Жилфонд в строке Каменоломней явно отмечен как региональный, Ремос — агрегатор только по структуре.

Ссылки получены из реально открытых страниц; HTTP/заголовки/структурные признаки записаны в external-sources.csv и evidence/external-sources.json. Динамические элементы «Черники» частично доступны в веб-представлении, DOM GET не подтверждает их работу. Ни одна внешняя форма не заполнялась. Чужие рекламные обещания, тарифы и отзывы не копируются и не рекомендуются как эталон. Жильё-просто.рф — UNK из-за недоступности.
