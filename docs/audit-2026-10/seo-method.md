# E — техническое SEO

Все 183 индексируемых URL: один H1, уникальные title/description/H1, абсолютный canonical на punycode production, og:url совпадает, изображения OG существуют. Нет статических сирот и глубины >3. Анкоры ключевых посадочных — anchor-texts.csv. Длины 30–70 / 70–170 — ориентиры владельца, не пороги санкций поисковых систем; соответствующие строки low.

Sitemap из production разобран XML-парсером PowerShell: 183 url, без redirect/noindex, каждый отвечает 200. robots.txt разрешает обход и указывает правильный sitemap. lastmod единый 2026-10-14: совпадает с согласованным расширением контента, не доказывает отдельную дату изменения каждой карточки. Дата обновления данных конкретного объявления — updatedAt в listings-audit.csv, не общий lastmod.

Все 41 прежних адреса: HTTP 200 + мгновенный HTML meta refresh; цель 200 и самоссылающийся canonical, sitemap не содержит прежних адресов, цепочек нет. Это корректная реализация согласованного решения PR #42; не HTTP 301. Индексирование после переезда подтверждается только кабинетами — UNK.

HTTP/HTTPS, www, кириллица/punycode, /index.html, /sell, /sell/, GitHub URL и неизвестный адрес записаны в http-variants.csv, curl-выводы — evidence/curl-*.txt. /sell/ возвращает 404, не является внутренней ссылкой; /sell без слэша работает по правилам Pages. Сам факт лишнего URL с canonical — не доказательство вреда. .nojekyll — управляющий файл Pages, не публичная пользовательская страница.

Сходство: 5-словные шинглы Jaccard по основному контенту всех 183 страниц, без общей шапки/подвала/nav. Между HTML-узлами добавлены пробелы, чтобы не склеивать слова. Карточки, подписи и формы входят в main: общие предложения повышают сходство. Все пары >0.6 — duplicates.csv, интерпретация INF. Это повод добавлять данные, не массово закрывать страницы.

Schema: каждый блок парсится; RealEstateAgent соответствует подтипу LocalBusiness (https://schema.org/RealEstateAgent), BreadcrumbList/ListItem, Service и Article используются по смыслу. Offer у неподтверждённых объявлений и сторонний aggregateRating отсутствуют. geo и sameAs совпадают с конфигом. openingHoursSpecification не заполняется, пока неизвестны дни; это соблюдает решение владельца. Отклонение строгого E.164 — E-062. Полный schema.org reasoner и Google rich-results eligibility — UNK; синтаксическая проверка не обещает расширенный результат.

При анализе первоначальный скан принял 27 ссылок на существующие WebP за отсутствующие HTML. Кандидаты отклонены после проверки файлов, в итоговых находках их нет.
