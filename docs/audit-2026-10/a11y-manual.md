# C — доступность

FACT: 454 axe-запуска (227 страниц × 390/1440) плюс 82 запуска исходных redirect-интерстиций с временно снятым meta refresh в памяти. Исходные переадресации не содержат нарушений A/AA по проверенным правилам. В основной таблице redirect не наследует ошибки целевой страницы.

22 группы axe, из них две на служебном Google verification (title/lang) — не дефекты пользовательского шаблона. Отдельно C-023 — ручной сценарий начального фокуса меню. Дубликаты сгруппированы по шаблону, исходные селекторы каждой страницы сохранены.

Ручной разбор: иерархия заголовков всех индексируемых страниц не содержит пропусков уровней, H1 один. Все поля lead-форм имеют label; отдельное согласие не отмечено. Статус role=status задаёт неявный aria-live=polite. Видимый :focus-visible: outline 3px, offset 4px, снимок manual-focus-390.png. Меню открывается Enter и закрывается Escape, но начальный фокус не перемещается в панель. Факт воспроизведён после чистой production-сборки, вне тестовой fixture.

391 переход к якорям в мобильном viewport: все цели существуют, начало целевого блока попадает в экран (anchor-scroll.csv). Это проверка начала секции; читабельность каждого элемента внутри секции ей не гарантируется.

Контраст: отчёт axe содержит конкретные цвета, фон, отношение и размер шрифта; пример подписи телефона 3.13:1 вместо 4.5:1. Визуально проверены снимки типов; это не сертификация соответствия WCAG и не тест с реальным экранным диктором.
