## Проверки, связанные с новым текстом

Узкое правило donor-аудита разрешает только точное название транспортной развязки из утверждённого текста Virgo и его поисковую версию в нижнем регистре. Общее ограничение для чужих географических упоминаний сохранено; отдельный тест проверяет, что посторонние упоминания и файлы по-прежнему не разрешены.

Проверка полноты описаний сравнивает видимый текст с источником, игнорируя только пробелы и оформление абзацев. Она не опирается на случайное вхождение полного текста внутри структурированных метаданных. Дословность исходного описания Virgo проверяется отдельно.
