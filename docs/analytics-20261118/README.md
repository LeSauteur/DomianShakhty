## Что собирается

Просмотры страниц; раскрытия телефона `phone_reveal`; клики по номеру `phone_click`; открытия и скачивания рекламных материалов; копирование текста и ссылок; запросы просмотра, отправки и результаты форм; действия в каталоге и калькуляторе. Клик по телефону отражает нажатие, а не подтверждённый разговор.

Сбор начинается только после согласия посетителя. При отказе, на localhost и с `qa=1` тег не загружается. Персональные поля форм исключены из событий. В глобальной конфигурации GA4 адрес страницы очищен до разрешённых рекламных параметров, а у referrer удалены query и hash, чтобы эти значения не добавлялись автоматически к следующим событиям.

[Документация Google по конфигурации page_location/page_referrer](https://developers.google.com/analytics/devguides/collection/ga4/reference/config).

## Специальные параметры GA4

Созданы с областью действия «Событие»:

| Название в отчёте | Параметр события |
| --- | --- |
| Объект | object_id |
| Агент | agent_id |
| Место кнопки | placement |
| Роль контакта | contact_role |
| Формат рекламы | format |
| Источник обращения | source_cta |
| Тип объекта | object_type |
| Тип страницы | page_type |

Определения появляются в стандартных обработанных отчётах после обработки данных Google; проверка доставки выполняется отдельно после публикации. Данные за время до подключения восстановить нельзя.
