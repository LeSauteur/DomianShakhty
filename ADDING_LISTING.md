# Как добавить объект вручную

**Контакт по всем объектам:** по умолчанию используется администратор из `site.config.json` → `listingContact` (Елена Ларионова, +7 918 850-44-88). Телефон не копируется в запись объекта. `agentId` указывает ответственного за объект, но не меняет контакт для обращения. Во всех телефонных блоках подробной карточки номер администратора раскрывается по кнопке. Личные страницы агентов сохраняют их контакты.

**Привязка к агенту:** по решению владельца от 18.11.2026 объект принадлежит приславшему его агенту. Проверяйте имя и email отправителя каждого отдельного письма, сопоставляйте с профилем в `src/data/team.json` и задавайте `agentId`. В одной цепочке Gmail может быть несколько разных объектов; уточнение цены или повтор письма не создаёт новый объект. Сохраняйте источник и дату в отчёте импорта. Старые объекты, добавленные месяц и более назад без агента, остаются без `agentId`, с контактом администратора. Не назначайте их по сходству адресов или фотографий. После сборки проверяйте не только подпись агента в карточке, но и появление объекта в его профиле. Пример подтверждённой сверки: `docs/attribution-20261118/README.md`.

Цены в данных указывайте целым числом рублей: 6.3 / 6,3 млн / 6300 → 6 300 000 ₽; 1,950 млн → 1 950 000 ₽; 3,650 млн → 3 650 000 ₽. Уточнения из последующих писем имеют приоритет.

1. Скопируйте запись из `src/data/listings.json` и задайте новый постоянный `id` латиницей, без цены в имени.
2. Укажите `type` и `format`: квартира вторичка — `apartment-secondary` / `secondary`, новостройка — `apartment-newbuild` / `newbuild`, дом — `house-secondary` / `secondary`, участок — `land` / `land`.
3. Обновите `title`, `price` (рубли числом), `area` (м² для квартиры/дома), `landArea` (сотки для дома/участка), `rooms`, `address`, `description`, `features`, `status` и `updatedAt`. Если точный адрес неизвестен, укажите район без номера дома.
4. Создайте `assets/images/listings/<id>/` и положите туда все предоставленные фотографии в WebP с сохранением пропорций: `hero.webp`, `01.webp`, `02.webp`, `03.webp`, `04.webp`.
5. Пропишите пути: `image.src` → `hero.webp`, остальные элементы `gallery` → `01.webp`–`04.webp`. Для всех изображений укажите понятный `alt` и реальные `width` / `height`.
6. Проверьте цену, характеристики, право размещения и фотографии. После проверки поставьте `verified: true`. Установите `status: "available"` для объекта в продаже.
7. Добавьте `id` в `src/data/listing-media-manifest.json` со статусом `done` и полным списком файлов.
8. Выполните `npm run build`, затем `npm run qa`.

## Как заменить фотографии

Замените WebP под теми же именами в папке объекта. Если имена и размеры не меняются, `listings.json` менять не нужно. Запустите `npm run build` и `npm run qa`.

Если агент выбирает обложкой уже существующий кадр, поменяйте местами объекты `image` и соответствующий элемент `gallery`, включая src/alt/width/height. Так сохраняются все фотографии, а новый URL обложки исключает показ старого кадра из кеша. Проверьте новую обложку в каталоге, профиле агента, подробной карточке и рекламном комплекте.
